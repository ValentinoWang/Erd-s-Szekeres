# Artifact manifests

The complete compact research archive contains `full-artifact-inventory.json` and `SHA256SUMS.txt`. Together they freeze the path, byte size, and SHA-256 identity of every ES7 artifact available at archive time, including large CNF, DIMACS, LRAT, PDF, and harness ZIP objects that are unsuitable for ordinary Git history.
