# AI-use disclosure

Generative AI assisted exploratory decomposition, alternative-route generation, code scaffolding, debugging suggestions, report organization, and manuscript editing.

AI output was never treated as mathematical evidence. Statements reported as theorems were retained only after one or more of the following: a complete human-readable proof, exhaustive exact enumeration, independent implementation, unit-propagation certificate replay, or direct clause/model checking.

Human authors remain responsible for all claims, code releases, citations, and submission metadata. AI systems are not authors.
