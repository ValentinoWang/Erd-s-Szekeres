# Research timeline

This is a compact map of the main proof-search rounds. Detailed reports and machine records are stored under `rounds/` and the historical code snapshots.

| Stage | Main result |
|---|---|
| P0 | Frozen orientation/signotope encoding, independent checker, adversarial mutation suite, and first anchored run obstructions. |
| Rounds 2-4 | Exact anchored-8, anchored-9, and anchored-10 residual classifications; thousands of translated guard clauses; fixed-window transition graphs shown highly connected. |
| Round 5 | Tight-path/Horn compression for anchor-containing convex-seven constraints; treewidth analysis; exhaustive onion-layer size cover. |
| Round 6 | Global tight-path formulation; exact fixed-prefix 2-SAT right-extension oracle; first proof-carrying CEGAR blockers. |
| Rounds 7-9 | Symbolic right-extension formula, bounded projections, exact width-two and width-three spectra, guarded-Horn interpretation, and binary-edge factorization. |
| Rounds 10-12 | Depth-bounded reachability circuits, strict depth hierarchy witnesses, shared antichain/DAG representation, and parallel ZDD/Benders executors. |
| Rounds 13-17 | Large RUP antichains, selected-projection exact model counts, complete five/six/seven-element prime layers, and LRAT-style replay. |
| Round 18 | Propagation-complete OBDD theorem and finite-convergence theorem for shared guarded-Horn Benders circuits. |
| Round 19 | Exact eight/nine-element transition relation, strong connectivity and two-cycle; restoration of the complete width-two projection; direct full-master and depth-three interfaces retained. |
| arXiv preparation | Theorem-first manuscript, visual QA, ASCII metadata, and slim source bundle below arXiv's upload limit. |
