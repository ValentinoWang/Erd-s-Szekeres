# Historical proof-search programs

The complete compact archive contains 162 deduplicated Python, C, C++, and shell programs extracted from the historical harness ZIPs. They include:

- frozen-encoding generation and independent checking;
- signotope enumeration and convex-seven guard mining;
- anchored-8/9/10 residual and transition analysis;
- tight-path/Horn formula construction;
- treewidth and onion-layer analysis;
- symbolic right-extension and bounded projection;
- exact path-oracle, CEGAR, antichain, and shared-circuit tooling;
- adversarial mutation and clean-room validation scripts.

Use [`../archives/README.md`](../archives/README.md) to reassemble the archive. Current paper-facing programs are directly browsable under [`../src/`](../src/).
